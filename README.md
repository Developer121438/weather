# 🌦️ Weather App

A simple, responsive weather application built with **HTML, CSS, and JavaScript** that allows users to check real-time weather information for different cities around the world.

The application uses the OpenWeather API to retrieve current weather conditions and display important weather details in a clean, user-friendly interface.

## ✨ Features

* 🌍 **Search by City:** Find weather information for different cities around the world.
* 🌡️ **Real-Time Weather:** Display the current temperature in Celsius.
* 💧 **Humidity Information:** Check the current humidity level.
* 💨 **Wind Speed:** View the current wind speed.
* ☁️ **Weather Conditions:** Display weather conditions such as clear skies, clouds, and rain.
* ⚠️ **Error Handling:** Show an error message when a city cannot be found or the API request fails.
* 📱 **Responsive Design:** Use the application on different screen sizes.

## 🛠️ Technologies Used

* **HTML5** — Structures the application.
* **CSS3** — Styles the interface and makes the application responsive.
* **JavaScript** — Handles user interactions, API requests, and dynamic weather updates.
* **OpenWeather API** — Provides current weather data.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project

Navigate to the project folder:

```bash
cd Weather-App
```

### 3. Configure the API Key

This project uses the OpenWeather API.

1. Create an account on [OpenWeather](https://openweathermap.org/).
2. Obtain an API key.
3. Add the API key to the appropriate location in your JavaScript code.

**Important:** Never publish a private API key in a public repository. For a public portfolio project, consider using a backend to protect your API key.

### 4. Run the Application

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

Enter a city name and check its current weather information.
